# Microsoft

`microsoft-symbol.svg` es el símbolo oficial descargado de:

https://learn.microsoft.com/en-us/entra/identity-platform/media/howto-add-branding-in-apps/ms-symbollockup_mssymbol_19.svg

Procedencia y uso para identificar el inicio de sesión con Microsoft:
https://learn.microsoft.com/en-us/entra/identity-platform/howto-add-branding-in-apps

`MicrosoftBrand.Symbol` conserva los cuatro rectángulos, colores y viewBox del SVG como un DrawingImage de WPF para renderizarlo nítido a distintas escalas. No requiere acceso a Internet ni un motor SVG en ejecución. La marca pertenece a Microsoft; no forma parte de la licencia MIT del código original del launcher.
